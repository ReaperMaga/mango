# Keyboard shortcuts

Mango is built to be driven from the keyboard. On macOS, <kbd>⌘</kbd> replaces <kbd>Ctrl</kbd> in every shortcut below.

## Global

| Keys | Action |
| --- | --- |
| <kbd>Ctrl</kbd> <kbd>K</kbd> | Command palette |
| <kbd>Ctrl</kbd> <kbd>N</kbd> | New chat (with no project open: New project) |
| <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>N</kbd> | New chat in its own git worktree (Unity VCS: its own workspace) |
| <kbd>Ctrl</kbd> <kbd>O</kbd> | Open folder |
| <kbd>Ctrl</kbd> <kbd>J</kbd> or <kbd>Ctrl</kbd> <kbd>`</kbd> | Show or hide the terminal |
| <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>T</kbd> | New terminal |
| <kbd>Ctrl</kbd> <kbd>B</kbd> | Show or hide the sidebar |
| <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>G</kbd> | Switch the sidebar between chats and changes |
| <kbd>Ctrl</kbd> <kbd>,</kbd> | Open or close Settings |
| <kbd>Ctrl</kbd> <kbd>\\</kbd> | Split the chat area, or close the split |
| <kbd>Ctrl</kbd> <kbd>W</kbd> | Close the current tab |
| <kbd>Ctrl</kbd> <kbd>1</kbd> … <kbd>9</kbd> | Switch to tab 1 to 9 |

While the terminal has focus, only <kbd>Ctrl</kbd> <kbd>K</kbd> and the terminal toggle reach Mango; every other key goes to the shell. While Settings is open, only <kbd>Ctrl</kbd> <kbd>K</kbd>, <kbd>Ctrl</kbd> <kbd>,</kbd> and <kbd>Esc</kbd> act.

## Command palette

The palette (<kbd>Ctrl</kbd> <kbd>K</kbd>, or the search field in the titlebar) searches chats, projects and actions: new chat, open folder, new project, clone repository, get started (install and sign in to agents), show or hide the terminal, sidebar and changes, split, settings, theme.

| Keys | Action |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | Move the selection (on macOS also <kbd>Ctrl</kbd> <kbd>P</kbd> / <kbd>Ctrl</kbd> <kbd>N</kbd>) |
| <kbd>Page Up</kbd> <kbd>Page Down</kbd> | Move the selection by a page |
| <kbd>Enter</kbd> | Run the selected item |
| <kbd>Esc</kbd> | Close |

## Chat

| Keys | Action |
| --- | --- |
| <kbd>Enter</kbd> | Send the message |
| <kbd>Shift</kbd> <kbd>Enter</kbd> | New line |
| <kbd>Esc</kbd> | Stop the running turn |
| Middle click on a tab | Close the tab |

## Sidebar

| Keys | Action |
| --- | --- |
| <kbd>Enter</kbd> | Open the focused chat |
| <kbd>Alt</kbd> <kbd>↑</kbd> / <kbd>Alt</kbd> <kbd>↓</kbd> | Move the focused chat up or down |
| <kbd>Enter</kbd> / <kbd>Esc</kbd> while renaming | Save / cancel the new title |

## Changes and branches

| Keys | Action |
| --- | --- |
| <kbd>Ctrl</kbd> <kbd>Enter</kbd> in the message box | Commit (or check in) |
| <kbd>↑</kbd> <kbd>↓</kbd> | Move between file rows |
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>Enter</kbd> in the branch popup | Pick a branch or action |
| <kbd>→</kbd> / <kbd>←</kbd> in the branch popup | Open / close a branch's actions, or a folder of branches |
| <kbd>Esc</kbd> | Close the branch popup |

## Terminal panel

| Keys | Action |
| --- | --- |
| <kbd>←</kbd> <kbd>→</kbd> on a terminal tab | Previous / next terminal |
| <kbd>Home</kbd> / <kbd>End</kbd> on a terminal tab | First / last terminal |
| <kbd>Enter</kbd> in an exited terminal | Start the shell again |

## Start screen

| Keys | Action |
| --- | --- |
| <kbd>Delete</kbd> on a recent project | Remove it from Recent |
